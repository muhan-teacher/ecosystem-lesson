# 생물과 환경 — 학생 주도 탐구 수업 웹앱

통합과학 Ⅱ-1-1 「생물과 환경」 (고1) 수업용 웹앱입니다.

- `student.html` — 학생 탐색용: 질문 만들기 → 연못 생태계 분류 → 상호 관계 탐정 → 모둠 탐구 카드(패들렛 게시용) → 스스로 확인
- `teacher.html` — 교사 설명용: 수업 흐름표, 도입 기본 개념, 발표 후 10분 개념 설명 슬라이드, 타이머
- `index.html` — 두 앱으로 가는 첫 화면

## 학습 목표
- 기본: 생태계 구성요소를 생물요소와 비생물요소로 구분하고, 생물이 환경과 서로 영향을 주고받음을 말할 수 있다.
- 심화: 생물요소를 생산자·소비자·분해자로 구분하고, 사례로부터 생물과 환경 사이의 상호 관계를 설명할 수 있다.

## 수업 흐름 (50분)
| 단계 | 시간 | 활동 | 도구 |
|---|---|---|---|
| 도입 | 7분 | 지렁이 질문 제시, 기본 개념 미니 설명 | 교사용 앱 「도입」 |
| 탐구 1 | 8분 | 개인: 질문 만들기, 연못 생태계 구성요소 분류 | 학생용 앱 ①② |
| 탐구 2 | 12분 | 모둠: 상호 관계 사례 탐정 → 우리 모둠 사례 카드 제작 → 패들렛 게시 | 학생용 앱 ③④, 패들렛 |
| 발표 | 8분 | 갤러리 워크(패들렛 댓글로 질문·피드백), 2~3모둠 발표 | 패들렛 |
| 개념 설명 | 10분 | 학생 발표를 연결해 개념 정리 | 교사용 앱 「개념 설명」 |
| 정리 | 5분 | 스스로 확인하기, 처음 질문에 다시 답하기 | 학생용 앱 ⑤ |

학생 입력은 각 기기 브라우저(localStorage)에만 저장되며 서버로 전송되지 않습니다.
